# KISAXI

APRS I-Gate ソフトウェア KISAXI の紹介ページと配布用のリポジトリです。

- 紹介ページ: https://nao700.github.io/kisaxi-release/
- ダウンロード: [Releases](https://github.com/Nao700/kisaxi-release/releases/latest)

Windows 10 / 11、Linux (x64)、Raspberry Pi で動く単体実行ファイルです。ランタイムのインストールは不要です。

RF で送信するにはアマチュア無線局の免許が必要です。
