主な機能

I-Gate（RF ⇄ APRS-IS）

RF で受信したパケットを qAR 付きで APRS-IS へ送出します。TCPIP・NOGATE・RFONLY などを含むものや 30 秒以内の重複は送りません。ローカル局宛のメッセージは RF へ中継します。

デジピータ

WIDE1-1 と自局コールサイン宛のパケットを中継します。設定で WIDE2-n の中継も選べます。

TNC 接続

KISS シリアル（COM ポート、/dev/ttyUSB0 など）と KISS TCP に対応しています。Direwolf や UZ7HO Soundmodem と組み合わせて使えます。

地図表示

OpenStreetMap 上に APRS シンボル、コールサイン、移動局の軌跡（日付や時間で区切るかどうかは設定で選べます）を表示します。局をクリックすると距離・方位・速度・高度・コメント・生パケットが見られます。

ビーコン・オブジェクト

RF と APRS-IS のビーコンをそれぞれの間隔で送信します。オブジェクトとアイテムは最大 10 件まで登録でき、座標は地図のクリックで指定できます。

パケット解析

通常位置、圧縮位置、Mic-E、オブジェクト、アイテム、メッセージ、ステータス、NMEA、気象に対応しています。Shift_JIS のコメントも文字化けしません。

局リスト・パケットモニター

受信局を検索し、RF / IS で絞り込めます。パケットモニターは RF 受信・IS 受信・送信・ゲートを色分けして表示します。

メッセージ

メッセージの送受信ができます。ACK は自動で返し、未達の場合は最大 5 回まで再送します。

ログと復元

パケットは日別のログに保存されます。受信した局は終了時に保存され、次回起動時に復元されます。

自動更新

新しいバージョンが出ると画面上部にお知らせが出て、ボタン一つでダウンロードと入れ替え、再起動までできます。ダウンロードしたファイルはチェックサムなどを確かめてから入れ替えます。設定で、見つかったら自動で更新することもできます（既定はオフ）。

最長距離 (DX) の記録

RF で直接受信した最も遠い局を記録して画面上部に表示します。更新するとステータスで送信し、aprs.fi のステータス欄に表示されます。リセットのタイミング（毎日・毎時）と距離の単位（km / mi）は設定で選べます。

出力・アンテナ (PHG) と通達範囲

送信出力・アンテナ高・利得・指向を設定すると、ビーコンに PHG を付けて送信します。計算した通達範囲を、地図に自局を中心とした円で表示します。

位置あいまい局の表示

座標の桁を伏せて送っている局（Mic-E を含む）は、マーカーにカーソルを乗せるとその範囲をピンクの四角で地図に表示し、マーカーを範囲の中心に合わせます。

aprs.fi で機種名を表示

正式に登録された宛先 (TOCALL) APKSXI で送信するので、aprs.fi などで KISAXI からの送信だとわかります。

画面

操作はすべてブラウザの管理画面から行います。

画面の写真は準備中です。

対応環境

OSファイル
Windows 10 / 11（64bit）aprsigate-windows-x64.exe
Linux（x64）aprsigate-linux-x64
Raspberry Pi 3 / 4 / 5、Zero 2 W（64bit OS）aprsigate-linux-arm64
Raspberry Pi 3 / 4、Zero 2 W（32bit OS）aprsigate-linux-armv7
Raspberry Pi Zero / Zero W（非推奨）aprsigate-linux-armv6

Raspberry Pi で uname -m が aarch64 なら 64bit OS です。Pi Zero / Zero W は CPU が非力で動作が不安定になる可能性があるため、おすすめしません。

どれもランタイムのインストールは不要な単体実行ファイルです。Windows で互換モードを使う必要もありません。

はじめ方

Windows

  1. aprsigate-windows-x64.exe を好きなフォルダに置いて実行します。
  2. ブラウザで管理画面（http://127.0.0.1:8073/）が自動で開きます。
  3. 「設定」タブでコールサイン・パスコード・位置・TNC を入力し、「保存して適用」を押します。

署名していない exe のため、初回起動時に SmartScreen の警告が出たら「詳細情報」から「実行」を選んでください。コンソールウィンドウを閉じると終了します。

Linux / Raspberry Pi

chmod +x aprsigate-linux-arm64
./aprsigate-linux-arm64
  • シリアル TNC を使う場合は、実行ユーザーを dialout グループに追加します：sudo usermod -aG dialout $USER
  • 別の PC やスマホから管理画面を開くときは、Tailscale の利用をおすすめします。Pi で sudo tailscale serve --bg 8073 を実行すれば、Tailscale を入れた端末だけから、家の中でも外出先でも安全に開けます。Tailscale を使えないときは -listen 0.0.0.0:8073 を付けて起動しますが、認証機能がないので信頼できる LAN 内だけで使ってください。

systemd で常駐させる例（/etc/systemd/system/aprsigate.service）。「ユーザー名」は実行するユーザーに置き換えてください。いまの Raspberry Pi OS には pi ユーザーがありません。

[Unit]
Description=APRS I-Gate
After=network-online.target

[Service]
User=ユーザー名
WorkingDirectory=/home/ユーザー名/aprsigate
ExecStart=/home/ユーザー名/aprsigate/aprsigate-linux-arm64 -nobrowser
Restart=always

[Install]
WantedBy=multi-user.target

設定のポイント

項目内容
パスコードAPRS-IS のパスコードを入力します。-1 にすると受信専用になります。
シンボルI-Gate ではテーブル I とシンボル & の組み合わせが一般的です。
フィルターm/50 で自局から半径 50 km の局を受信します。r/緯度/経度/距離 なども使えます。
Direwolf接続方式を「KISS TCP」、アドレスを 127.0.0.1:8001 にします。
UZ7HO SoundmodemSoundmodem 側で KISS サーバーを有効にし、アドレスを 127.0.0.1:8100 にします。

付録

Raspberry Pi のデスクトップから起動する

毎回ターミナルでコマンドを打たずに、デスクトップやメニューのアイコンをダブルクリックして起動できるようにするスクリプトです。

kisaxi-pi-launcher.zip をダウンロード
  1. zip の中の aprsigate-start.sh・desktop-setup.sh・kisaxi_app_icon.png を、実行ファイルと同じフォルダ（例：~/aprsigate）に置きます。
  2. ターミナルで一度だけ次を実行します（sudo は不要です）。 
    bash ~/aprsigate/desktop-setup.sh
  3. デスクトップとメニューの「インターネット」に KISAXI のアイコンができます。ダブルクリックすると、ターミナルの画面つきで起動して管理画面が開きます。
  • 「このファイルを実行しますか」と聞かれたら「実行」を選びます。
  • 止めるときは、開いたターミナルの画面で Ctrl+C を押すか、画面を閉じます。
  • 機種に合う実行ファイル（arm64 / armv7 / armv6 / x64）は自動で選ばれます。
  • systemd で常駐させている間にアイコンを押すと、二重には起動せず管理画面だけが開きます。
  • アイコンを消すときは bash ~/aprsigate/desktop-setup.sh --remove を実行します。

ファイルを個別に見る：aprsigate-start.sh ・ desktop-setup.sh ・ kisaxi_app_icon.png

Bluetooth で無線機とつなぐ（Linux / Raspberry Pi）

TH-D74 / TH-D75 / TM-D750 を Bluetooth で TNC として使えるように、/dev/rfcomm0 を作るスクリプトです。再起動後も自動で使えるように登録します。実機での動作確認は TM-D750 で行っています。

bt-tnc-setup.sh をダウンロード
  1. 無線機の Bluetooth をオンにして、Pi とペアリングします（デスクトップ右上の Bluetooth アイコン、または bluetoothctl で）。
  2. ダウンロードしたファイルを実行ファイルと同じフォルダ（例：~/aprsigate）に置き、ターミナルで次を実行します。 
    sudo bash ~/aprsigate/bt-tnc-setup.sh
  3. KISAXI の「設定」で TNC を「KISS シリアル」、ポートを /dev/rfcomm0 にして「保存して適用」を押します。
  • 無線機側は KISS モードにして、データの通信先を Bluetooth にします。
  • シリアルポートのチャンネルを自動で調べられないときは番号を聞かれます。TM-D750 は 27 でした。
  • やめるときは sudo bash ~/aprsigate/bt-tnc-setup.sh --remove を実行します。
  • Windows ではスクリプトは不要です。ペアリング後に「その他の Bluetooth 設定」→「COM ポート」に出る「発信」側の COM を選びます。

注意事項

  • RF で送信するにはアマチュア無線局の免許が必要です。
  • 送信パス（WIDE1-1 など）は地域の運用ルールに合わせてください。
  • 管理画面には認証機能がありません。-listen 0.0.0.0 で公開するときは、信頼できる LAN 内だけで使ってください。
